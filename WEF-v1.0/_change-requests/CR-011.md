# CR-011 — Real Estate Development Module

**Approved By:** Methodology Governance Board

Added the **Real Estate Development Module** via the New Module Development Process, using the Expired Listing Specialist (Commercial-Weighted) Module as the structural starting point. Intentionally scoped broad, per user instruction, as a foundation for future asset-class-specific niche sub-modules. Grounded in research on investment-manager website-structure patterns, SEC Regulation D Rule 506(b)/506(c) general solicitation requirements, the Interstate Land Sales Full Disclosure Act, Fair Housing Act design-and-construction requirements, and pre-construction rendering disclaimer conventions.
