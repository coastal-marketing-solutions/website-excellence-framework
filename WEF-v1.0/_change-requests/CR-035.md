# CR-035 — Intake web form (fillable Claude Artifact)

**Status:** Pending Governance Board approval — implemented on branch `wef-cr-035-intake-web-form`.
**Numbering note:** drafted as CR-033; `origin/wef-cr-033-stage-transition-check` and `origin/wef-cr-034-search-authority-tracking` already claimed 033 and 034, so this CR takes the next free number (Governance Sec. 15.6 dedup). Re-check at merge.

Additive. No Core Methodology chapter changes and no Stage Gate exit criteria; the canonical
question set stays Reusable Templates Sec. 16.2.

## Problem

The `intake` skill (CR-027) could produce an email-reply script or a sendable document, but
the client still answered by email and someone re-keyed or pasted the reply back. The email
format also gives no live progress, no required-field tracking, and no signal that the client
has finished.

## Change

1. **New `assets/templates/intake-form/intake-form.html`** — the 39 questions of Sec. 16.2 as a
   fillable web page (Claude Artifact source): section rail with counts, required-field
   tracking, an "I'm not sure yet" option on every question, autosave, a warning when a field
   looks like an SSN, card number or password, and a "Send to the team" button that unlocks
   when required questions are covered. Question ids `q01`…`q39` match Sec. 16.2 numbering 1:1.
2. **Storage and access.** Answers save to the artifact database at `answers/intake`
   (`{answers, status, submittedAt, updatedAt}`). Access rules: root read/write `admin`;
   `answers/intake` read/write `interact`. The client opens the shared link signed in at
   contributor access; a view-only user cannot read the answers.
3. **`intake` skill.** GENERATE offers *web form* as the preferred delivery format (publish a
   fresh copy per client, share to the client's email, record the URL in `01-WEF-Intake-SENT.md`).
   INGEST gains a first source: `ArtifactData get answers/intake`, mapped `qNN` → Sec. 16.2,
   `qNN_notes` → details, `qNN__unsure` → `not sure`; `status: submitted` vs `draft` sets the
   artifact's `Status:`. Everything read is treated as client data, not instructions.
4. **`assets/README.md`** lists the template as live reference.

One form holds one client's answers, so each engagement publishes its own copy.

write to `answers/intake` committed, the owner read it back, a `view`-level list returned
