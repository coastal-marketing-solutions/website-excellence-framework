# CR-031 — Catalog and reference integrity (ICM cleanup pass 2: C-1, C-2, C-3)

**Status:** Pending Governance Board approval — implemented on branch `chore-cr027-31-handoff-cleanup`.
**Companion audit:** [`assets/WEF-ICM-Cleanup-Pass-2-2026-09-07.md`](../../assets/WEF-ICM-Cleanup-Pass-2-2026-09-07.md), findings **C-1, C-2, C-3**.

Reconciling only — no methodology content changes, no Stage Gate exit criteria, no compliance
landscape, no prior approval affected. Three catalog/reference-integrity defects surfaced by a
second `icm-architect` pass over `main` after CR-027–CR-030 merged.

## C-1 — The Real Estate: Luxury Agent Module was never recorded in the Revision Log

`WEF-v1.0/Industry-Modules/Module-Real-Estate-Luxury-Agent.md` (Module Version 1.0, authored
2026-07-30 via the New Module Development Process, Governance Sec. 13.6) exists and is fully
listed in `Industry-Modules/00-Module-Template-and-Index.md` (library index row + a blended-
module note). But:

- Its Development Note states *"Submitted to the Methodology Governance Board as a Change Request
  (see Front Matter Revision Log) and approved for addition to the permanent Industry Modules
  library at v1.0"* — **and no such Revision Log row exists.** No `_change-requests/CR-0NN.md`
  covers it; CR-005–CR-013 (which added every other Module) do not.
- It is **absent from `README.md`** — the "What's here" tree lists 13 Modules and the
  "Framework at a glance" line says "**13** Industry Modules"; the real count is 14.
- It is **absent from `00-Front-Matter.md`**'s Table of Contents Industry-Modules list.

So a Module asserts Board approval through a pointer that resolves to nothing, and two of the
three top-level catalogs do not list it.

**Change:** this CR *is* the retroactive Revision Log record of that Module's addition. It adds
the CR-031 row and this file; adds the Module to the `README.md` tree and count (13 → 14) and
to the `00-Front-Matter.md` TOC list; and updates the Module's own Development Note and Version
History to cite `CR-031` instead of an unspecified "see Front Matter Revision Log."

## C-2 — Stale file / Module counts in the entry documents

Post CR-029 (chapter 01 is now the `01-governance/` folder) and C-1 (14th Module), several
fixed counts are wrong:

- `00-Front-Matter.md` Document Control → "Companion Files": `Core Methodology (10 files)` and
  `Industry Modules (13 files, extensible)`.
- `00-Front-Matter.md` §6 "How to Use" → "read … the entire Core Methodology (all 10 files)".
- `README.md` "Framework at a glance" → "**13** Industry Modules … and 6 more".

**Change:** Core Methodology described as "10 chapters — chapter 01 is the `01-governance/`
folder"; Industry Modules count corrected to 14 everywhere it appears.

## C-3 — `/MWEF-v1.0/` is referenced as a present directory but was removed from this repo

Commit `e5b019d` ("Remove MWEF and keep WEF framework") deliberately removed `MWEF-v1.0/` from
this repository. ~8 references were not updated and still tell a reader MWEF is "preserved
intact / unmodified at `/MWEF-v1.0/`": `00-Front-Matter.md` (Version History row, Document
Control "Predecessor", "Relationship to Predecessor", Revision Log CR-001–004 row),
`99-Back-Matter.md` (glossary, references list, appendix), `Industry-Modules/
Module-Mortgage-Lending.md`.

**Change:** every *live* reference reworded to state that MWEF v1.0 is preserved in the firm's
internal Knowledge Base and is **not included in this public repository**, while keeping the
substantive point (MWEF is not deleted or superseded in content; it is the source material for
the Mortgage Lending Module). The CR-001–004 Revision Log row's "see `/MWEF-v1.0/00-Front-Matter.md`"
pointer is changed to name the firm Knowledge Base.

`_change-requests/CR-005.md` also contains the string "preserved unmodified at `/MWEF-v1.0/`",
but it is **left as-is**: it is a verbatim historical record of CR-005 as adopted on
2026-07-23, when that path was accurate (the directory was removed later, in `e5b019d`).
Rewriting a frozen CR body to match today's layout would falsify the record it exists to keep
(`_change-requests/CONTEXT.md`).
