# CR-029 — Split the Governance chapter into `01-governance/` (F-8) *(Working Draft)*

**Status:** Pending Methodology Governance Board approval
**Board decision:** **Option C** (split + pointer stub + deferred opportunistic reference sweep), per [`assets/CR-029-Board-Decision-Memo-Governance-Chapter-Split.md`](../../assets/CR-029-Board-Decision-Memo-Governance-Chapter-Split.md)
**Companion audit:** [`assets/WEF-ICM-Architecture-Review-2026-09-07.md`](../../assets/WEF-ICM-Architecture-Review-2026-09-07.md), finding **F-8**

## Problem

`01-Governance.md` was one 885-line file (~40k tokens) carrying ~15 distinct jobs. ICM invariant
1 (one folder, one job) and invariant 7 (load only what the step needs, ~2k–8k tokens): a task
needing only the Decision Register schema pulled the whole chapter into context. RETRO-013/014
trace partly to *"a rule buried in this file was not re-read at the point it applied."*

## Change (Option C)

1. Split into `WEF-v1.0/Core-Methodology/01-governance/` — one file per section
   (`01-initialization.md` … `15-retrospectives.md`), content **verbatim**, section numbers
   unchanged and global to the chapter (`Sec. 13.5` is `### 13.5` inside `13-policies.md`).
2. Added `01-governance/CONTEXT.md` — the recursive L1 router: *question → file → sections*,
   plus the chapter contract (reads / writes / human-checks).
3. Reduced `01-Governance.md` to a pointer stub: chapter intro + a section→file table + a note
   that existing `01-Governance.md` links still resolve and new references should name the
   section file. **Kept, not deleted** — so ~185 existing bare `Governance, Sec. N` references
   across the manual keep resolving unchanged (section numbers are stable).
4. Repointed the handful of references that named `01-Governance.md` *as a file* and are about
   selective loading: `intake`, `new-engagement`, `wef-sync` skills; `README.md` tree;
   `AGENTS.md`.
5. **Deferred:** the full sweep of ~185 bare `Governance, Sec. N` references to the
   `Governance — 13-policies.md, Sec. 13.5` form, and updating live engagement-KB navigation
   layers. Tracked in [`assets/CR-029-Reference-Sweep-Checklist.md`](../../assets/CR-029-Reference-Sweep-Checklist.md),
   done opportunistically as each file is next touched — the mechanism CR-027 used for the
   file-naming convention and CR-028 used for the thin Revision Log.

## Why Option C, not B (all-in-one sweep)

The split is cleanly reviewable; the 185-reference sweep is where the risk concentrates and
would produce a diff no reviewer can verify line-by-line. Spreading it across small reviewed
edits is lower-risk and already-proven practice.

## Validation

- Concatenating the 15 section files' bodies reproduces the original chapter's section span
  (verified: whitespace-normalized identical apart from the removed inter-section `---` rules).
- Every bare `Governance, Sec. N` reference still resolves via stable section numbers + the stub.
- `01-governance/CONTEXT.md` links all resolve; `git diff --check` clean.
- Sweep checklist enumerates every remaining file with a bare reference.
