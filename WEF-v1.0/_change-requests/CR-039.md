# CR-039 — Add the `website-build-registry` skill

**Status:** Pending Governance Board approval

## Problem

Every WEF engagement accumulates accounts, hosting, domains, plugins, and integrations that
sit on the agency's own accounts during the build. Nothing in the framework kept a running,
auditable record of where each piece lives and who holds it, separate from the build itself —
so a client had no way to verify nothing was hidden, and a handover or vendor switch meant
reconstructing that picture from scratch.

## Change

**New `.agents/skills/website-build-registry/SKILL.md`** — maintains, per engagement:

1. `BUILD-REGISTER.md` — current state: domains/DNS, hosting/deployment, code/content,
   versions, plugins/tools, integrations, Google/listings, backups, secrets (names only, never
   values), renewal calendar, open items — each row carries "Held by" and "Last verified".
2. `CHANGELOG.md` — one dated entry per build change, with how to undo it.
3. `reports/YYYY-MM-register-summary.md` — a one-page, plain-language monthly client summary.
4. `PROJECT-RULES.md` — the engagement's own house rules (source-of-truth file for business
   facts, forbidden claims, approval gates), created once per engagement and then just read.

Runs on first deploy/upload, on any hosting/DNS/plugin/account change, monthly regardless, and
before any client meeting or handover. Read-only/write-only to its own five files — it never
deploys, buys, sends, posts, or changes an account setting itself. Never writes secret values,
never invents a fact/date/owner, and keeps each client's data in its own engagement folder.
Bundled templates (`assets/`) keep every engagement's register in the same shape.

**AGENTS.md** — routing row added under "Route by task".

Additive only. No Stage Gate exit criteria change; no existing file's behavior is altered.

## Validation

- `SKILL.md` frontmatter present and valid; skill packaged and validated with `skill-creator`'s
  own validator before submission.
- Secrets rule: template files contain no value fields, names only.
- `AGENTS.md` routing table row added, consistent with existing rows' format.
