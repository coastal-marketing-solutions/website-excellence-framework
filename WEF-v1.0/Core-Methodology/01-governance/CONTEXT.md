# `01-governance/` — Core Methodology, Governance

Governance is the operating system every other Core discipline and every Industry Module runs on.
It is entirely industry-agnostic — the same Charter structure, Decision Register, Knowledge Base,
and handoff protocol apply to a mortgage lender, a law firm, or a SaaS company. **Read the whole
chapter before beginning any engagement work.** This router exists so a later, narrower task
loads only the section it needs.

Section numbers are stable and global to the chapter: `Governance, Sec. 13.5` is `### 13.5`
inside `13-policies.md`. A cross-reference that names only `Sec. N` still resolves — it just
doesn't name the file yet (the file-naming sweep is deferred; see
[`assets/CR-029-Reference-Sweep-Checklist.md`](../../../assets/CR-029-Reference-Sweep-Checklist.md)).

## Contract

- **Reads:** the active Industry Module (for Module Injection Points, Sec. 9); the Project Charter
  and Decision Register of the engagement in hand.
- **Writes:** nothing in canon — these are reference sections. Engagement artifacts
  (Charter, Decision Register, KB) are written into the engagement KB, not here.
- **Human-checks:** Core changes to any of these sections go through a Change Request +
  Methodology Governance Board (Sec. 13.1–13.2), written up in
  [`../../_change-requests/`](../../_change-requests/) and indexed in the Front-Matter Revision Log.
