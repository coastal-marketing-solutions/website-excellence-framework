# 91-addenda: scope addenda

Not a Stage Gate. One sub-folder per addendum that extends scope after the Charter was approved (for example a data product, a portal, an extra page set). Each addendum has its own mini-structure and a Decision Register id.

**Naming:** `NN-<short-name>/` (for example `01-listing-data/`), containing at least `SCOPE.md` (what is added, what is not, who approved, `DEC-` id), `OPEN-QUESTIONS.md`, and an `output/` folder.

Addenda may reuse Stage Gate templates (research, architecture, build, QA) but are tracked here, not as new top-level gates.
