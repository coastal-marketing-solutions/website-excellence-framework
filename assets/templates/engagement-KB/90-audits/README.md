# 90-audits: audit reports

Not a Stage Gate. A permanent home for audits of any kind, at any time, so findings are not stranded inside a stage's `output/` or a chat.

**Naming:** `Audit-YYYY-MM-DD-<type>.md` (types: `design`, `seo`, `accessibility`, `performance`, `compliance`, `qa`, `security`, `content`). One file per audit; re-audits get a new dated file.

**Each audit file states:** scope and method, what could not be checked, a score or verdict, findings by severity with location and fix, and the Action Items Sheet item ids or Decision Register ids it spawned.
