# 92-handoffs: superseded handoffs

Not a Stage Gate. The **current** handoff is `../HANDOFF.md` at the KB root. When a new handoff replaces it, move the previous one here as `HANDOFF-YYYY-MM-DD.md` (date of that handoff).

At each Stage Gate close, optionally save a snapshot of the Action Items Sheet here as `Action-Items-Sheet-Snapshot-YYYY-MM-DD.md` (open and done items, with outcomes), so the record survives outside the sheet.

See Core Methodology, AI Workflows Sec. 2.6.
